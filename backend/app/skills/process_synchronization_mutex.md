## 核心内容

### 1. 临界资源与临界区
**临界资源**：一次只允许一个进程访问的共享资源（如打印机、共享变量）。
**临界区**：访问临界资源的那段代码。

### 2. 同步与互斥
**互斥 (Mutual Exclusion)**：多个进程不能同时进入临界区。
- 目的：保护临界资源。
- 例子：两个进程不能同时写同一个文件。

**同步 (Synchronization)**：进程间的执行顺序协调。
- 目的：保证逻辑正确性。
- 例子：生产者-消费者问题中，消费者必须等生产者生产后才能消费。

### 3. 信号量 (Semaphore)
信号量是一个整型变量，配合两个原子操作：
- **P 操作 (wait)**：`S = S - 1`，若 S < 0 则阻塞。
- **V 操作 (signal)**：`S = S + 1`，若 S ≤ 0 则唤醒一个等待进程。

**互斥信号量**：初值为 1，用于实现互斥访问。
**同步信号量**：初值根据资源数量设定（如 0 或 N），用于进程间同步。

## 经典案例

### 案例 1：生产者-消费者问题
```c
Semaphore mutex = 1;      // 互斥访问缓冲区
Semaphore empty = 10;     // 空槽位数
Semaphore full = 0;       // 已用槽位数

// 生产者
while(true) {
    生产数据item;
    P(empty);          // 等待空槽位
    P(mutex);          // 进入临界区
    将item放入缓冲区;
    V(mutex);          // 离开临界区
    V(full);           // 增加已用槽位
}

// 消费者
while(true) {
    P(full);           // 等待有数据
    P(mutex);          // 进入临界区
    从缓冲区取出item;
    V(mutex);          // 离开临界区
    V(empty);          // 增加空槽位
    消费item;
}
```
